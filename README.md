## Descripción del proyecto

Este proyecto tiene como objetivo analizar la evolución de las emisiones mundiales de dióxido de carbono (CO₂) a través del tiempo, utilizando información obtenida de Our World in Data.

## Desarrollo

Para realizar el proyecto se llevaron a cabo las siguientes actividades:

1. Descarga y exploración de los datos.
2. Limpieza y preparación de la información.
3. Análisis exploratorio de los datos.
4. Elaboración de gráficas para visualizar la evolución de las emisiones.
5. Aplicación de un modelo de regresión lineal.
6. Interpretación de los resultados y conclusiones.

## Fuente de información

Our World in Data: https://ourworldindata.org/co2-emissions
